DAY 10 — LAB 10
Aviation Image Generation
 
Step 1 — Understand Image Generation
Image generation uses artificial intelligence to create a new image from a text prompt. The generated visual is based on instructions such as the subject, style, environment, lighting and composition.
Generation vs Retrieval
Image Retrieval	Image Generation
Finds an existing image	Creates a new image
The image already exists	The image is produced from a prompt
Usually provides an original source	May not have a conventional original source
Example: searching an official airport website	Example: generating an airport campaign visual
Copyright and usage rights must be checked	Copyright, disclosure and usage rights must still be checked
Key learning: An attractive AI-generated image should not automatically be considered accurate or suitable for professional aviation use. It must be reviewed for realism, safety, branding, privacy and misleading details.
 
Step 3 — Weak Image Prompt
Weak Prompt
Create an airport image.
Prompt Diagnosis
Prompt Component	Present or Missing?	What Should Be Added?
Subject	Partially present	Specify passengers, airport terminal or another main subject
Style	Missing	Specify photorealistic, corporate photography or illustration
Environment	Missing	Specify modern international airport terminal
Lighting	Missing	Specify natural daylight or professional lighting
Aspect ratio	Missing	Specify 16:9, 1:1 or another required format
Intended use	Missing	State whether it is for a presentation, advertisement or social media
Brand restrictions	Missing	State that real airline/airport logos should not be included
Text restrictions	Missing	Request no readable promotional or personal text
Accuracy instructions	Missing	Request realistic people, aircraft, equipment and safe passenger behaviour
The weak prompt provides very little direction, so the image-generation tool has to make many decisions independently.
 
Step 4 — Five-Part Image Prompt
Business Requirement
Create a presentation visual showing young travellers using self-service technology inside a modern airport terminal.
Image-Prompt Component	Student Response
Subject	Diverse young adult travellers using self-service check-in kiosks
Medium or style	Professional photorealistic corporate photography
Environment	Clean, spacious modern international airport terminal and self-service check-in area
Lighting	Bright natural daylight with realistic soft shadows
Aspect ratio	16:9 landscape suitable for a business presentation
Structured Prompt
Create a professional, photorealistic image of a diverse group of young adult travellers using self-service check-in kiosks inside a modern international airport terminal. Show a clean, spacious environment with realistic travel bags and clear passenger movement. Use bright natural daylight and a neutral blue-and-white colour palette. Use a 16:9 landscape aspect ratio suitable for a business presentation. Do not include airline logos, airport names, readable personal information, boarding-pass details or promotional text.
